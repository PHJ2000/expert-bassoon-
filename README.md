# Expert Bassoon - Data Analysis Project

## 프로젝트 개요
**Expert Bassoon**은 **Jupyter Notebook과 Python을 활용한 데이터 분석 프로젝트**입니다.
이 프로젝트에서는 `pandas`, `matplotlib`을 사용하여 주어진 데이터(`atlantis.csv`)를 분석하고, 다양한 시각화를 수행합니다.

## 주요 기능
- **CSV 데이터 로드 및 정리** (`pandas` 사용)
- **기본 통계 분석** (평균, 중앙값, 분산 등)
- **데이터 시각화** (`matplotlib`을 활용한 그래프 생성)
- **Jupyter Notebook을 통한 실험적 분석**

## 프로젝트 구조
```
expert-bassoon/
│── .devcontainer/  # 개발 컨테이너 설정
│── data/
│   └── atlantis.csv  # 분석할 데이터셋
│── notebooks/
│   ├── lab1.ipynb  # 데이터 분석 노트북 1
│   ├── matplotlib.ipynb  # 데이터 시각화 예제
│   ├── new.ipynb  # 추가 분석 노트북
│── requirements.txt  # 필요 라이브러리 목록
│── LICENSE  # 프로젝트 라이선스
│── README.md  # 프로젝트 설명 파일
```

## 설치 및 실행 방법
1. **필수 라이브러리 설치**
    ```bash
    pip install -r requirements.txt
    ```
2. **Jupyter Notebook 실행**
    ```bash
    jupyter notebook
    ```
3. **노트북 파일 열기**
    - `notebooks/lab1.ipynb`
    - `notebooks/matplotlib.ipynb`

## 필요 라이브러리
